새 프로그램(앱) 추가하는 방법

이 포털에 새로운 웹 앱을 등록하려면 아래 2단계만 진행하시면 됩니다:

Step 1. 폴더 생성 및 앱 파일 넣기

최상위 폴더에 새 폴더를 만들고 그 안에 index.html 파일을 넣습니다.
(예: AndroidAppByHtml/가계부앱/index.html)

Step 2. index.html의 APPS_DATA에 항목 추가

최상위 index.html 코드 내 APPS_DATA 배열에 새 앱 정보를 한 줄 추가합니다: 

{
  id: 'budget-app',
  title: '가계부 계산기',
  description: '간편한 일일 지출 및 예산 관리',
  path: './가계부앱/index.html',
  icon: '💰',
  badge: '신규',
  category: '생산성/도구',
  tags: ['돈', '계산', '지출']
}
💡 Tip: GitHub 저장소에 push하면 GitHub Pages에서 추가된 앱을 즉시 실행하고 모바일 기기에서도 동일하게 이용할 수 있습니다.
